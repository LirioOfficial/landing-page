## 📌 Sobre o projeto

O **Lírio** é um projeto de desenvolvimento web que apresenta sua identidade visual, seus serviços, projetos e informações institucionais por meio de uma landing page moderna e responsiva.

A aplicação foi desenvolvida com foco em organização, experiência do usuário, reutilização de componentes e consistência visual.

## ✨ Funcionalidades

- Página inicial com apresentação do projeto.
- Seção institucional sobre o Lírio.
- Apresentação de serviços.
- Exibição de projetos.
- Seção de equipe.
- Área de contato.
- Navegação entre as seções da página.
- Interface adaptável a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **React.js** — desenvolvimento da interface.
- **Next.js** — estrutura e organização da aplicação.
- **JavaScript** — lógica e funcionalidades.
- **CSS3** — estilização e identidade visual.
- **HTML5** — estruturação do conteúdo.
- **Git e GitHub** — versionamento e colaboração.

## 🚀 Como executar o projeto

### 1. Pré-requisitos

- Node.js instalado.
- npm instalado.
- Git instalado.

### 2. Clonar o repositório

```bash
git clone https://github.com/LirioOfficial/landing-page.git
```

### 3. Entrar na pasta do projeto

```bash
cd landing-page
```

### 4. Instalar as dependências

```bash
npm install
```

### 5. Executar a aplicação

```bash
npm run dev
```

### 6. Acessar no navegador

```text
http://localhost:3000
```
